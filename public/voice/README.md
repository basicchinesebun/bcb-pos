# ສຽງຮຽກຄິວ — เสียงเรียกคิว

อัดเสียงภาษาลาว 12 ไฟล์วางในโฟลเดอร์นี้ แล้วระบบจะใช้เสียงนี้แทนเสียงสังเคราะห์ทันที
ไม่ต้องแก้โค้ดอะไรเลย ถ้ายังไม่มีไฟล์ ระบบจะใช้เสียงไทยไปก่อน

## ไฟล์ที่ต้องอัด

| ชื่อไฟล์ | พูดว่า |
|---|---|
| `prefix.mp3` | ອໍເດີໝາຍເລກ |
| `0.mp3` | ສູນ |
| `1.mp3` | ໜຶ່ງ |
| `2.mp3` | ສອງ |
| `3.mp3` | ສາມ |
| `4.mp3` | ສີ່ |
| `5.mp3` | ຫ້າ |
| `6.mp3` | ຫົກ |
| `7.mp3` | ເຈັດ |
| `8.mp3` | ແປດ |
| `9.mp3` | ເກົ້າ |
| `suffix.mp3` | ເຊີນມາຮັບສິນຄ້າຢູ່ໜ້າເຄົາເຕີ |

ระบบจะเล่นต่อกันแบบนี้ — คิว 0051:

    [ระฆัง] prefix · 0 · 0 · 5 · 1 · suffix

## วิธีอัดให้เสียงต่อกันแล้วลื่น

- **อัดในห้องเงียบ** ปิดแอร์ ปิดพัดลม
- **พูดจังหวะเดียวกันทุกไฟล์** โดยเฉพาะตัวเลข 0-9 ถ้าเร็วช้าไม่เท่ากันจะฟังสะดุด
- **ตัดความเงียบหัวท้ายออกให้หมด** ไม่งั้นจะมีช่องว่างยาวระหว่างตัวเลข
- ตัวเลขพูดสั้นๆ ห้วนๆ ได้เลย ไม่ต้องลากเสียง
- อัดด้วยมือถือก็พอ ไม่ต้องใช้ไมค์แพง

## ข้อกำหนดไฟล์

- นามสกุล `.mp3` ชื่อตรงตามตารางเป๊ะ (ตัวพิมพ์เล็ก)
- ไฟล์ละไม่เกิน ~50 KB (ตัวเลขควรสั้นกว่า 1 วินาที)
- รวมกันไม่ควรเกิน 300 KB

## ทดสอบ

วางไฟล์ครบแล้ว push ขึ้น branch แล้วกดปุ่ม 📢 บนการ์ดออเดอร์
ถ้ายังได้ยินเสียงไทย แปลว่าชื่อไฟล์ไม่ตรง หรือยังไม่ครบ 12 ไฟล์
